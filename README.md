# Mangesh Bodke

Portfolio site. React, TypeScript, and Vite.

## Local

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
```

The build writes `dist/`.

## Vercel

Import this repository. The app lives at the repo root.

- Framework: Vite
- Build command: `npm run build`
- Output directory: `dist`
- Node.js: 22
